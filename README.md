# TDS_Test_Stability

MATLAB programs for the stability analysis of time-delay systems using advanced Lyapunov-Krasovskii functionals and delay-dependent Lyapunov matrix approaches.

This repository implements computational methods based on Legendre polynomial approximations and delay-dependent formulations, avoiding LMI-based techniques and reducing conservatism in stability conditions.

The code incorporates an efficient algorithm for the construction of structured block matrices associated with delay Lyapunov matrices, developed during postgraduate research and reported in the article:

"An efficient algorithm for the construction of a block matrix depending on the delay Lyapunov matrix for testing stability of time-delay systems"

The repository is directly linked to peer-reviewed publications in high-impact journals and is referenced as supplementary material in the following SIAM Journal article:

https://epubs.siam.org/doi/abs/10.1137/23M1610859

Additionally, this software supports a broader research line in time-delay systems and stability analysis, with multiple related publications available in the author's academic profiles (Google Scholar / ResearchGate), reflecting the continuity and development of this research area.

## Features
- Stability analysis for time-delay systems
- Delay-dependent Lyapunov matrix construction
- Legendre polynomial approximation
- Reduced conservatism compared to LMI-based approaches
- Efficient matrix construction algorithm

## Usage
Run the main script to reproduce stability analysis examples.
